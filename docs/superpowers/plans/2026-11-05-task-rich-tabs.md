# Вкладки в описании задания

**Цель:** добавить согласованный блок вкладок внутрь RichEdit с обычным форматированием и медиа.

**Архитектура:** один документ Tiptap; узел `taskTabs` содержит узлы `taskTab`, а каждая вкладка — обычные блоки редактора. HTML хранится в существующем `taskRich`; активная вкладка остаётся локальным состоянием просмотра и не вызывает сохранение. Обычный readonly HTML получает переключатели через отдельный клиентский компонент.

**Стек:** существующие Tiptap 3, React 19, Next.js 16, sanitize-html, Node test runner и Playwright; новые зависимости не требуются.

## Контракт документа

```html
<div class="aq-task-tabs" data-aq-tabs="true">
  <div class="aq-task-tabs__panels">
    <div class="aq-task-tabs__panel" data-aq-tab="true" data-aq-tab-title="Легенда"><p>Описание</p></div>
    <div class="aq-task-tabs__panel" data-aq-tab="true" data-aq-tab-title="Ориентиры"><p>Фото и текст</p></div>
  </div>
</div>
```

## Реализация

- [x] `scripts/taskRichTabs.test.js`: сохранение структуры, подписей и медиа через серверную очистку HTML; схема и команды Tiptap без базы данных. Добавлен `npm run test:rich-text-tabs` и включён в `premerge:app`.
- [x] `helpers/taskRichTabs.js`: ограничения (8 вкладок, название до 40 символов), нормализация названия, начальный документ блока с двумя пустыми вкладками.
- [x] `components/cabinet/task-rich-editor/taskTabsExtension.js`: узлы, вставка блока, переключатели, переименование, добавление, копирование, перестановка, удаление с подтверждением, управление историей. Команда не вставляет вложенный блок; selection следует выбранной вкладке.
- [x] `components/cabinet/TaskRichEditor.js`: расширения, кнопка и slash-команды; общая панель форматирования; атомарная вставка медиа в исходное место загрузки с отображением позиций через основные и добавочные транзакции.
- [x] `helpers/sanitize.js`: разрешены только необходимые атрибуты структуры вкладок, запрет обработчиков событий и скриптов сохранён.
- [x] `helpers/taskRichTabsDom.js`, `components/game/TaskTabsHtmlView.js`, `components/cabinet/TiptapContentView.js`: readonly HTML, стрелки/Home/End, остановка скрытого аудио/видео, сохранение DOM при повторном рендере с тем же HTML.
- [x] `styles/global.css`: стили редактора и readonly для мобильных экранов и обеих тем; цвета вкладок следуют теме задания.
- [x] `docs/ui-patterns.md`, `docs/roadmap.md`: описаны формат блока, локальность выбранной вкладки и выполненная часть rich-text редактора.
