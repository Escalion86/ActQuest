# Prequel Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Добавить приквел как отдельную предыгровую механику для зарегистрированных команд с вводом кодов до фактического старта, влиянием на результаты и поддержкой `classic`, `photo` и `story`.

**Architecture:** Приквел хранится в `Games.prequel`, а прогресс команды — в `GamesTeams.prequelProgress`, чтобы не смешивать его с task-based логикой. Ввод кодов выносится в отдельный web API, расчёт влияния приквела — в отдельный слой внутри `buildGameResultComputed`, а `story`-ветка получает безопасный DSL-адаптер приквельных эффектов.

**Tech Stack:** Next.js App Router, React 19, Mongoose 9, MongoDB 7, Jotai, React Query v5, Tailwind CSS v4, PropTypes, smoke/verify scripts.
