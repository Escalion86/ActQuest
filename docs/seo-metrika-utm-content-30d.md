# ActQuest: Метрика + UTM + Контент-план (30 дней)

## 1) Цели и события для Яндекс.Метрики

## Базовые принципы

- Отслеживаем только ключевые действия, влияющие на лид.
- Во всех событиях передаём город (`city`) и страницу (`page_type`), чтобы видеть эффективность по локациям.
- События называем в едином формате: `aq_<действие>`.

## Рекомендуемые события

1. `aq_click_register`
- Когда: клик по CTA регистрации (`Начать игру`, `Записаться на игру`).
- Параметры: `city`, `page_type`, `placement` (hero/footer/article/city-page).

2. `aq_click_phone`
- Когда: клик по номеру телефона.
- Параметры: `city`, `page_type`, `phone`.

3. `aq_click_chat`
- Когда: клик по ссылке на Telegram-чат.
- Параметры: `city`, `page_type`, `chat_target` (krsk/nrsk/ekb).

4. `aq_click_schedule`
- Когда: переход к расписанию/списку игр.
- Параметры: `city`, `page_type`.

5. `aq_view_city_page`
- Когда: просмотр city-страницы.
- Параметры: `city`.

6. `aq_view_article`
- Когда: просмотр статьи.
- Параметры: `article_slug`, `city`.

7. `aq_scroll_75`
- Когда: пользователь долистал 75% страницы.
- Параметры: `page_type`, `city`.

## Цели (Goals) в Метрике

1. Цель `REGISTRATION_CLICK`
- Условие: событие `aq_click_register`.

2. Цель `CHAT_CLICK`
- Условие: событие `aq_click_chat`.

3. Цель `PHONE_CLICK`
- Условие: событие `aq_click_phone`.

4. Цель `SCHEDULE_CLICK`
- Условие: событие `aq_click_schedule`.

5. Составная цель `ENGAGED_SEO_SESSION`
- Логика: `aq_view_city_page` + (`aq_scroll_75` или `aq_click_chat` или `aq_click_register`).

## Отчёты (еженедельно)

1. Лиды по городам: `REGISTRATION_CLICK + CHAT_CLICK + PHONE_CLICK`.
2. Конверсия city-страниц: `aq_view_city_page -> REGISTRATION_CLICK/CHAT_CLICK`.
3. Вклад статей: `aq_view_article -> переходы в city-страницы`.

## 2) UTM-шаблоны

## Единые правила

- `utm_source`: источник (`yandex`, `google`, `telegram`, `vk`, `direct`, `seo`).
- `utm_medium`: тип трафика (`organic`, `cpc`, `referral`, `social`).
- `utm_campaign`: город + тип (`krsk_city_seo`, `ekb_articles`, `nrsk_reviews`).
- `utm_content`: место клика (`hero_chat_btn`, `city_footer_chat`, `article_inline_cta`).
- `utm_term`: для рекламных ключей (в SEO можно не заполнять).

## Шаблон для ссылок в Telegram-чаты с сайта

```text
https://t.me/<chat_or_invite>?utm_source=seo&utm_medium=organic&utm_campaign=<city>_city_seo&utm_content=<placement>
```

Пример:

```text
https://t.me/+XXXXXXX?utm_source=seo&utm_medium=organic&utm_campaign=ekb_city_seo&utm_content=city_hero_chat_btn
```

## Шаблон для внутренних CTA на регистрацию

```text
/cabinet/login?mode=register&utm_source=seo&utm_medium=organic&utm_campaign=<city>_city_seo&utm_content=<placement>
```

Пример:

```text
/cabinet/login?mode=register&utm_source=seo&utm_medium=organic&utm_campaign=krsk_city_seo&utm_content=article_inline_cta
```

## Стандартные `placement` значения

- `home_init_chat_btn`
- `city_hero_chat_btn`
- `city_footer_chat_btn`
- `article_inline_cta`
- `article_end_cta`

## 3) Контент-план на 30 дней (3 города)

- Неделя 1-4: 2 материала в неделю.
- За 30 дней: 8 материалов (по 2-3 на город).

## Структура каждой статьи (обязательно)

1. H1 с городом и ключом.
2. Короткий лид-абзац с оффером.
3. Практический блок (список, шаги, рекомендации).
4. FAQ на 3-5 вопросов.
5. CTA-блок:
- `Записаться на игру`
- `Перейти в чат проекта`
- телефон.

## Минимальные KPI на месяц

1. 8 публикаций в индексе Яндекса.
2. Рост переходов из органики на city-страницы минимум на 20%.
3. Минимум 30 целевых кликов суммарно:
- `aq_click_register`
- `aq_click_chat`
- `aq_click_phone`.
