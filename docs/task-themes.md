# Оформление заданий

В общей части редактора classic/photo-заданий поле «Оформление всех заданий»
выбирает `game.taskTheme`: `cyberpunk-light` или `cyberpunk-dark`.
Оформление едино для всех заданий игры, включая новые задания, подсказки,
сообщения после выполнения и альтернативные пути classic. Индивидуальных тем
у заданий нет. При копировании заданий игры копируется и общая тема.

Тема интерфейса пользователя не меняет фон и цвета этих блоков.
Редактор и просмотр используют общий `TaskThemeSurface` и стили `.aq-task-theme`.
Текст без заданного автором цвета получает цвет темы, заголовки и ссылки —
акцентный цвет. Явно заданные цвета текста и выделения сохраняются и имеют
приоритет над цветами темы. Палитра цвета в редакторе доступна при любой теме.
Тема не переписывает HTML. Автор проверяет сочетание своих цветов с выбранным
фоном в предпросмотре: и сохранённое задание, и черновик используют общую
`game.taskTheme`, включая подсказки и сообщение после выполнения.

Существующие игры без `taskTheme` и неизвестные идентификаторы используют
`cyberpunk-dark`. Массовое изменение базы не требуется. Тема сохраняется на уровне игры через обычный API редактирования игр;
закрытая игра защищена от её изменения. Старые поля темы внутри заданий
игнорируются: источником оформления служит только `game.taskTheme`.

## Добавление тем

Каталог `helpers/taskThemes.js` содержит идентификатор, название, цветовую схему,
фон, текст, акцент, поверхность рамок и границу. Для «Стимпанка», «Зомбиленда»
и других оформлений добавить запись с постоянным идентификатором. Список в
редакторе и нормализация обновятся автоматически. Для дополнительных визуальных
эффектов использовать `[data-task-theme="идентификатор"]` внутри `.aq-task-theme`,
не глобальный `.dark`. Не использовать выбранный пользователем ID как CSS или URL.

Проверка контраста палитр и наследования: `node --no-warnings --test scripts/taskThemes.test.js`.
При расширении каталога проверить редактор, предпросмотр и экран команды
в светлом и тёмном интерфейсах, включая цитаты, рамки и ссылки.
