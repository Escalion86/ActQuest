# Время заданий и расписание подсказок classic

С 2026-11-04 задания classic могут иметь разные лимиты и расписания подсказок.
Общие настройки игры служат значениями по умолчанию. Старые игры продолжают
использовать общий лимит и равные интервалы, миграция документов не нужна.

## Настройка в редакторе

В настройках игры задаются продолжительность задания по умолчанию и расписание
подсказок: одинаковый интервал, свои интервалы или отключение автоматики.
В редакторе отдельного задания блок «Время задания и подсказки» позволяет
включить свой лимит и выбрать собственное расписание либо наследовать общее.
Лимит и расписание общие для всех вариантов одного этапа: время выбора пути
входит в лимит задания.

Интервалы задаются последовательно: `15, 10` минут означает выдачу на 15-й,
25-й, 35-й минуте и далее. Последний интервал повторяется для оставшихся
подсказок. Редактор показывает рассчитанные моменты выдачи от старта.
Можно добавить ноль, одну, две или больше подсказок. Под блоком подсказок есть
галочка «Разрешить неполный набор подсказок» (по умолчанию выключена).
Без неё проверка перед запуском требует подсказки для каждого момента выдачи
до конца задания; редактор показывает предупреждение «Задание недозаполнено»
с текущим и необходимым количеством. Галочка отключает только эту проверку
для своего задания или варианта, включая photo; остальные проверки сохраняются.
Черновик с недостающими подсказками можно сохранить.
Подсказка, назначенная после лимита задания, автоматически
открыться не успеет. Для задания без подсказок капитан может выполнить слив
сразу, если это действие разрешено настройками игры.

## Хранение и расчёт

- `game.taskDuration` — общий лимит в секундах.
- `tasks[].taskDuration` — положительный целочисленный лимит этапа; `null`
  или отсутствие поля означает наследование общего.
- `game.clueIntervals` — массив положительных целочисленных интервалов в
  секундах; `null` использует старый повторяющийся `game.cluesDuration`.
- `tasks[].clueIntervals` — индивидуальные интервалы; `null` наследует игру.
- `tasks[].allowIncompleteClues` — разрешение неполного набора подсказок;
  отсутствие поля равнозначно `false`. Для альтернативы хранится в её `content`.
- Пустой массив интервалов явно отключает автоматическую выдачу.

Общий источник правил — `helpers/taskTiming.js`. Web API задания, оба
web-движка classic, Game Control, статусы агентов и расчёт результата используют
одни лимиты и моменты подсказок. Индексы относятся к исходным заданиям, поэтому
настройки сохраняются при случайном маршруте. Переход после таймаута учитывает
лимит предыдущего задания и перерыв; новое задание получает свой лимит.

Досрочная подсказка в режиме сдвига времени начисляет остаток до конкретного
момента следующей подсказки. В режиме фиксированного штрафа сохраняется
настроенная стоимость. Телепорт уменьшает те же игровые часы: будущие
подсказки задерживаются, уже открытые сохраняются. Исходный `startTime`
не переписывается при этих действиях.

Проваленное или слитое задание не получает `endTime` и учитывается по полному
индивидуальному лимиту. Успешное длинное задание не обрезается общим лимитом
игры и не получает штраф за его превышение. Результат, таблица и анимация
используют лимиты отдельных этапов. `taskResults.taskDurationSeconds` хранит
применённый лимит; Game Control также возвращает текущий лимит и остаток до
следующей подсказки.

Новые поля сохраняются в редакторе и Mongoose, копиях игр/заданий, тестовых
прогонах и данных кабинета. Правила игр с индивидуальным временем или своим
расписанием блокируются после запуска; закрытые игры защищены от изменения
лимитов и расписаний. Механики photo и story не используют эти переопределения.

## Проверка

В `npm run test:classic-game-process` включены проверки индивидуальных лимитов,
неравных интервалов, свободного количества подсказок, клиентского валидатора,
таймаутов, случайного маршрута, досрочных подсказок, телепорта, результатов,
Mongoose и копирования. Отдельно проверяются статусы агентов, обзор заданий,
защита закрытых игр и старые таймеры.

Изолированный браузерный стенд с настоящими компонентами, Modal и CSS проверяет
ширины 390/1440 px: общее расписание, индивидуальные 90 минут, своё расписание,
отключение, наследование и ноль подсказок. Телепорт повторно проходит тот же
сценарий подтверждения, отказа и повторного запроса. Рабочая БД не используется;
авторизованный прогон с реальным сохранением остаётся отдельной проверкой.

Проверено 2026-11-04: 123 теста основного classic-набора и 81 дополнительная
проверка агентов, обзора, старых таймеров, копирования и закрытых игр прошли.
Production build, `smoke:app`, API-контракты и проверки безопасности прошли.
ESLint не обнаружил ошибок; существующие предупреждения проекта сохраняются.
