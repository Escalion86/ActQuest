# App Router Go-Live Checklist (Production)

Дата: 2026-04-04  
Период наблюдения: первые 24-48 часов после выката.

## 1. Предрелизный минимум

1. Выполнить `npm run premerge:app` на финальном коммите.
2. Убедиться, что переменные окружения совпадают с рабочими:
   - `NEXTAUTH_URL`
   - `NEXTAUTH_SECRET`
   - ключи Telegram/VK/TelefonIP/push
3. Проверить доступность:
   - `/api/health`
   - `/cabinet/login`
   - `/cabinet/games-upcoming`

## 2. Smoke сразу после выката (первые 15 минут)

1. Авторизация:
   - вход по паролю,
   - восстановление пароля,
   - проверка callbackUrl.
2. Кабинет:
   - `/cabinet`, `/cabinet/games-upcoming`, `/cabinet/games-past`,
   - `/cabinet/teams`, `/cabinet/profile`.
3. Админка:
   - `/cabinet/admin/users`, `/cabinet/admin/teams`, `/cabinet/admin/transactions`.
4. API:
   - `GET /api/cabinet/games-list?...`
   - `GET /api/cabinet/team-details?...`
   - `GET /api/cabinet/user-details?...`

## 3. Что мониторить 24-48 часов

1. Ошибки API (`/api/cabinet/*`, `/api/[location]/*`):
   - доля `5xx`,
   - всплески `401/403`.
2. Сессии:
   - частота разлогина после refresh,
   - жалобы на потерю роли/профиля.
3. Ключевые пользовательские сценарии:
   - загрузка списков игр/команд/пользователей,
   - открытие модалок и переходы по карточкам,
   - регистрация/отмена регистрации на игру.
4. Push/уведомления:
   - успешная подписка/отписка,
   - ошибки при отправке user/game push.

## 4. Пороги тревоги (триггеры отката)

Считать релиз нестабильным и запускать rollback, если выполняется хотя бы одно:

1. `5xx` по `/api/cabinet/*` устойчиво > 2% более 15 минут.
2. Массовые `401/403` для авторизованных пользователей после refresh (подтверждено логами и обращениями).
3. Не работает вход в кабинет или недоступны ключевые экраны (`/cabinet/games-upcoming`, `/cabinet/admin/users`) более 10 минут.
4. Критический регресс данных:
   - невозможно редактировать игру/команду,
   - не открываются модалки просмотра сущностей.

## 5. Rollback-план (коротко)

1. Откат на предыдущий стабильный релиз.
2. Очистка CDN/edge-кэша (если применимо).
3. Проверка восстановления:
   - login,
   - `/cabinet/games-upcoming`,
   - `/cabinet/admin/users`.
4. Фиксация инцидента:
   - время начала/окончания,
   - affected маршруты/API,
   - root cause,
   - action items.

## 6. Критерии успешного завершения go-live

1. За 24-48 часов нет срабатываний порогов отката.
2. Нет повторяемых жалоб на сессию/логин/списки кабинета.
3. Ошибки в логах единичные и некритичные.
4. Можно закрывать пункт roadmap:  
   `Логи и мониторинг подтверждают стабильность в течение контрольного окна`.
