# AGENTS.md — руководство для Codex

## Описание проекта

Это специальный сайт и одновременно Telegrem бот, для организации квестов. Данный проект позволяет создавать систему заданий, а также ответов на них пользователей с дальнейшей выдачей новых заданий. Также есть возможность рассчета результатов по баллам или по затраченному времени.

## Быстрая ориентация при потере контекста

Проект ActQuest — это Next.js сайт + сервер + Telegram-бот (в одном репозитории) для управления автоквестами.

Ключевые домены:

- Пользователи (`/schemas`, `/server`, `/telegram`) связаны по `telegramId`.
- События/квесты хранятся в схемах и пишутся в `/pages/api` и `/server`.
- UI — в `/pages`, `/components`, стили через Tailwind.

Где смотреть в первую очередь при правках:

1. `/pages/api` — API-эндпоинты для событий, команд, регистрации.
2. `/telegram` — парсеры обновлений, команды, связь с базой (старый flow).
3. `/helpers` и `/utils` — утилиты с проверками, валидацией, форматированием.
4. `/schemas` — основная структура БД, ключи пользователей и заданий.

## Текущие важные задачи (на ближайшее время)

1. Перейти от Telegram-only регистрации на телефон + SMS/OTP (с переносом данных, где возможно).
2. Реализовать регистрацию через VK One Tap.
3. Интегрировать загрузку картинок через escalioncloud.ru.
4. Протестировать и стабилизировать авторизацию нового типа, минуя `telegramId` как обязательный идентификатор.

## Быстрый “what-next” roadmap

1. Миграция данных: в схеме пользователя добавляем поле `phone`, `vkId`, `primaryAuthMethod`.
2. Новый flow регистрации: `phone` → `OTP` → `/pages/api/auth/phone`.
3. Внедрить авторизацию JWT + сессии, убрать жесткую привязку `telegramId` в бизнес-логике.
4. Добавить VK One Tap (обмен `vk_token` → `vkId` → создание/логин пользователя).
5. Подключить escalioncloud: загрузка изображений через API, сохранение URL в моделях.
6. Прогонять E2E тесты для новых путей регистраций и миграции пользователей.

> Важно: при изменении схемы данных поддерживать режим “fallback” для старых Telegram-only аккаунтов, чтобы существующие пользователи не потеряли доступ.
